# ЛР6. Клиент API, mock и состояния UI

| Сценарий | Как воспроизвёл | Текст на экране |
| -------- | --------------- | --------------- |
| Загрузка | открыл `/` | Загрузка… |
| Пустой список | `mockFlags.empty = true` | Записей пока нет |
| Данные | обычная загрузка | таблица |
| 400 | `mockFlags.force400 = true`, отправка формы | Проверьте поля |
| 500 | `mockFlags.force500 = true` | Сервер не смог обработать запрос |
| Нет связи | `USE_MOCK = false`, API не запущен | Нет связи с сервером |

Двойной клик по «Создать» добавляет одну запись, кнопка на время запроса disabled.
`id` и `number` приходят из ответа (mock), форма их не вычисляет.
