# Заявки на проверку аномального энергопотребления

Организация: энергослужба КГЭУ
Студент: ФИО Шайхутдинова Алина Группа: ТРИС-3-23
Семестр 1 · 2026/2027

## Тема
Информационная система для учёта заявок на проверку аномалий в показаниях приборов учёта: диспетчер создаёт заявку, главный энергетик назначает исполнителя, инженер-энергетик ведёт заявку по статусам.

## Стек
Vue 3 + ASP.NET Core + PostgreSQL (код будет добавлен в следующих ЛР)

## Статус темы
Ждём утверждения
