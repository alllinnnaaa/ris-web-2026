# Заявки на проверку аномального энергопотребления

Организация: энергослужба КГЭУ
Студент: ФИО Шайхутдинова Алина Группа: ТРИС-3-23
Семестр 1 · 2026/2027

## Тема
Информационная система для учёта заявок на проверку аномалий в показаниях приборов учёта: диспетчер создаёт заявку, главный энергетик назначает исполнителя, инженер-энергетик ведёт заявку по статусам.

## Стек
Vue 3 + ASP.NET Core + PostgreSQL (код будет добавлен в следующих ЛР)

## Статус темы
Ждём утверждения

## Запуск клиента

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно http://localhost:5173
## Запуск сервера (backend)

```bash
cd backend
dotnet restore
dotnet run
```

- API: http://localhost:5000
- Swagger: http://localhost:5000/swagger
- Проверка живости: http://localhost:5000/health
- Сведения о приложении: http://localhost:5000/info

Ограничения ЛР7:
- данные заявок пока в памяти, после перезапуска пропадут;
- /health проверяет только живость процесса, а не создание заявки;
- настоящее создание заявок появится в ЛР8.
